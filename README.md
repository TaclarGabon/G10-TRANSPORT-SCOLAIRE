# G10 Transport Scolaire

Application de gestion du transport scolaire G10.

Version source issue de la version pilote G10 Scolaire validée en septembre 2026.

## Modules
- Administration
- Chef d’exploitation
- Espace chauffeur
- Direction
- Parent
- Documents & exports
- Circuits, zones, arrêts et établissements
- Abonnements et passagers non abonnés
- Recettes cash / Airtel Money
- Discipline et accès chauffeurs
- Indicateur Chauffeur du mois

## Important
Cette application utilise actuellement un backend et une base de données Hatchable. Le dépôt GitHub sert de sauvegarde/versionnage du code source. GitHub Pages seul ne remplace pas le backend.
